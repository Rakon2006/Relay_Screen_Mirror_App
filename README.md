# Relay_Screen_Mirror_App
Relay is a low-latency phone-to-PC streaming solution for Windows, designed for iPhone and Android over USB. It aims to deliver smooth 60 FPS video, low-latency audio, and direct streaming for gaming and content creation—eliminating the need for capture cards, Elgato, or expensive hardware.
